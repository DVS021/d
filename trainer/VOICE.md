# Озвучка тренера

Текущая версия использует как образец тембра пятисекундную пробу,
которую выбрал владелец голоса: `voice-preview-20261110.mp3`.
Проба была создана Chatterbox Multilingual v3 по предоставленной владельцем
записи. Она сохранена без замены. Сравнение с рабочим голосом находится
на странице `voice-check.html`; обе записи читают одну и ту же фразу.

Рабочие реплики генерируются локально в два этапа: Piper Denis читает точный
русский текст с темпом и паузами выбранной роли, OpenVoice V2 переносит тембр
из выбранной пробы. Это не прямой синтез всей библиотеки моделью Chatterbox.
Перенос тембра не воспроизводит все индивидуальные интонации человека;
сходство и разборчивость следует оценивать на слух по странице сравнения.
Встроенная водяная метка OpenVoice WavMark сохраняется.

Сотруднику и диспетчеру соответствуют короткие фразы, более спокойный темп
и паузы 0,36 секунды. Контролёру — более подробная проверка фактов и паузы
0,28 секунды. РОПу — управленческий разбор и паузы 0,24 секунды.
Содержание определяется отдельно для каждой доступной роли в каждом кейсе,
а не добавлением общего вступления к одному и тому же ответу.

В библиотеке 15 тем и 157 записей: условия, решения, объяснения и проба.
Фильтр роли сохраняет доступ ко всем темам в режиме «Общее». При смене роли
выбранная тема сохраняется, если она доступна новой роли; предыдущая речь
прерывается. Исправления кейсов находятся в `role-cases.js`, справочные
объяснения — в `engine.js`. Не добавляйте нормативы, которых нет в источниках.

Для повторной генерации нужны приватные локальные модели OpenVoice V2,
Piper Denis, Python 3.12 с PyTorch 2.6 CPU и ONNX Runtime, WavMark, ffmpeg:

```sh
ffmpeg -i trainer/voice-preview-20261110.mp3 -ar 22050 -ac 1 /private/preview-reference.wav
node scripts/build-trainer-audio.mjs --engine owner --workers 4 --threads 1 --python /path/to/venv/bin/python --model /private/openvoice-v2 --reference /private/preview-reference.wav --work-dir /private/voice-work --base-python /path/to/piper/venv/bin/python --base-model /private/ru_RU-denis-medium.onnx
npm test
npm run build
```

Используйте отдельный рабочий каталог для новой версии синтеза. Запуск
продолжается с готовых фрагментов. Имена MP3 зависят от версии алгоритма,
образца, текста и параметров подачи. Каталог аудио обновляется после
успешного синтеза всего набора. Затем рассчитывается `audio-levels.js`
с громкостью по 80-миллисекундным отрезкам для анимации рта.

Модели, исходная запись владельца и параметры голоса остаются вне сайта.
Обычная сборка использует готовые MP3; хостингу не нужны Python, модели,
API-ключи или внешний сервис синтеза. Проигрывание идёт через обычный
HTML-аудиоплеер. Подмена системным голосом и маршрутизация через Web Audio
отключены. Сайт не оценивает свободные ответы языковой моделью.
