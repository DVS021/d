# Русская озвучка тренера

С 09.11.2026 используется нейронный голос **Denis**, `ru_RU-denis-medium`,
синтезатор Piper 1.3.0. Предыдущая озвучка eSpeak заменена.
Синтез проходит локально. Во время просмотра сайта пользователь получает
готовые MP3, обращения к сервисам синтеза речи нет.

Источник модели: https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/denis/medium

В [карточке модели](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/denis/medium/MODEL_CARD)
для набора данных указана лицензия CC0. Синтезатор
[Piper](https://github.com/OHF-Voice/piper1-gpl) распространяется по GPL-3.0.
Модель, её исполняемые зависимости и исходные записи не включены в сайт.

Для воспроизведения сборки понадобятся Python 3.12, `piper-tts==1.3.0`,
`ffmpeg` и два файла из каталога модели: `.onnx` и `.onnx.json`.
SHA-256 использованных файлов:

- `ru_RU-denis-medium.onnx`: `15fab56e11a097858ee115545d0f697fc2a316c41a291a5362349fb870411b0a`
- `ru_RU-denis-medium.onnx.json`: `831c860dac0b5073eaa81610a0a638ec23d90a6cf8e5f871b4485c2cec3767c8`

В отдельном локальном окружении установите `piper-tts==1.3.0`, затем выполните:

```sh
node scripts/build-trainer-audio.mjs --python /path/to/venv/bin/python --model /path/to/ru_RU-denis-medium.onnx
npm test
npm run build
```

`voiceText` в `trainer/engine.js` подготавливает произношение: раскрывает
сокращения и записывает число автомобилей словами. Отображаемый текст
не меняется. `scripts/synthesize-trainer.py` добавляет 280 мс тишины после
каждого предложения и делает темп немного спокойнее (`length_scale=1.08`).
Громкость всех MP3 выровнена; формат — моно, 22 050 Гц, 64 кбит/с.

Имена файлов зависят от текста и версии озвучки, поэтому браузер получает
новые записи после публикации. Устаревшие записи удаляются только после
успешной генерации полного набора ответов. При обычной сборке повторный
синтез не нужен.
