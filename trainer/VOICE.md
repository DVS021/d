# Озвучка тренера голосом ведущего

С 11.11.2026 реплики генерируются по согласованному владельцем образцу
его голоса. Перед заменой владелец прослушал и одобрил пробную фразу.
Это синтезированная речь, а не запись того, как ведущий читает каждый ответ.

Синтез проходит локально. Сначала Piper Denis формирует разборчивую русскую
речь по точному тексту, затем OpenVoice V2 переносит тембр ведущего по
согласованному образцу. OpenVoice V2 распространяется по MIT; используется
исходный float32-граф конвертации в ONNX Runtime. Встроенная водяная метка
WavMark сохраняется. Такой порядок сохраняет произношение и состав фразы.
Исходная запись, образец, модель и голосовые параметры остаются вне репозитория.
На сайте хранятся только готовые MP3 с учебными текстами. Во время просмотра
сайт не обращается к внешним сервисам синтеза.

Для повторной генерации нужны Python 3.12, OpenVoice V2,
PyTorch 2.6.0 CPU, ONNX Runtime, WavMark, ffmpeg, отдельное окружение Piper
и локальные веса обеих моделей и приватный образец согласованного голоса:

```sh
node scripts/build-trainer-audio.mjs --engine owner --python /path/to/venv/bin/python --model /private/path/to/openvoice-v2 --reference /private/path/to/reference.wav --work-dir /private/path/to/work --base-python /path/to/piper/venv/bin/python --base-model /path/to/ru_RU-denis-medium.onnx
npm test
npm run build
```

Промежуточные записи сохраняются в `--work-dir`; повторный запуск использует
готовые фрагменты. После успешной генерации всего набора обновляется каталог
и удаляются только устаревшие MP3. Рабочий каталог должен находиться вне сайта.

`voiceText` подготавливает произношение сокращений и чисел. Видимые формулировки
не меняются. Ответы разделены на законченные фразы для устойчивого синтеза;
между фрагментами добавлены короткие паузы. Громкость MP3 выровнена.
Имена файлов включают версию голоса, чтобы браузер загрузил новые записи.

Предыдущий голос Piper Denis можно пересоздать явным выбором
`--engine piper --model /path/to/ru_RU-denis-medium.onnx` и подходящего Python-
окружения. По умолчанию используется голос ведущего. Piper и OpenVoice
нужны только для генерации: обычная сборка и хостинг используют готовые файлы.

В каталоге модели OpenVoice нужны `config.json` и `checkpoint.pth` из
https://huggingface.co/myshell-ai/OpenVoiceV2/tree/main/converter .
`converter.onnx` создаётся локально при первом запуске. Файл образца,
веса и рассчитанные голосовые параметры не включаются в публикацию.
С 12.11.2026 предусмотрено 50 озвученных ответов и 15 ситуаций с разборами.
Для тембра используются семь фрагментов первого участника из первых 89 секунд
предоставленной записи; другой участник, по словам владельца, вступает на 95-й.
`--reference` принимает WAV либо приватную папку WAV-фрагментов одного голоса.
Источник и голосовые параметры по-прежнему остаются вне сайта.

Озвучка переносит тембр ведущего, сохраняя русское произношение базового
синтеза. Она не воспроизводит все индивидуальные интонации; степень сходства
нельзя подтвердить только автоматическими проверками.

После генерации автоматически обновляется `audio-levels.js` — громкость по
80-миллисекундным отрезкам для анимации рта. Воспроизведение идёт через обычный
HTML-аудиоплеер, без Web Audio и без подмены системным голосом браузера.
