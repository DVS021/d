# Видео для сайта

Загружайте в эту папку MP4 или WebM. OGV также поддерживается.
Подпапки не сканируются. Названия на русском языке допустимы.

Например: `Кейс 2 — Контроль К3.mp4` появится в плеере как
«Кейс 2 — Контроль К3» без редактирования каталога.

При `npm run build` каталог создаётся автоматически. В локальной среде
достаточно обновить страницу. На интернет-сайте обновление появится после
успешной сборки и публикации новой версии GitHub Pages.

Через браузер GitHub можно загрузить файл до 25 МБ. Для более крупных
файлов используйте GitHub Desktop, оставаясь ниже лимита 100 МиБ на файл.
MP4 с H.264/AAC обычно совместим с большинством браузеров.

Обложку, описание и связанные стандарты можно дополнительно указать
в `assets/videos.js`. Ручная запись по тому же файлу имеет приоритет —
автоматическая карточка не дублируется. Сам файл остаётся с исходным именем.
